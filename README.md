# הרפתקת המתמטיקה 🔢

משחק מתמטיקה לנויה (כיתה ג') ולאלין (גיל הגן) — לשימוש משפחתי, על טאבלט סמסונג. **חשבון בלבד.**

## נויה — כיתה ג'

60 שלבים ב-10 עולמות, ובסוף כל עולם **מבחן**:

| עולם | נושא |
|---|---|
| 🔢 עיר המספרים הגדולים | המבנה העשרוני עד 1000: מאות/עשרות/אחדות, פירוק, השוואה (‹ › =), זוגי/אי-זוגי, ±10/±100, עיגול |
| 🌉 גשר החיבור והחיסור | חיבור וחיסור עד 1000 עם ובלי המרה/פריטה, מספר חסר |
| 🏝️ אי לוח הכפל | שליטה בכל לוח הכפל, גורם חסר, סדרות ודילוגים |
| ❄️ ממלכת החילוק | חילוק בכל המחלקים, **חילוק עם שארית** (שני חלונות תשובה: מנה ושארית) |
| 🌋 הר הכפל הגדול | כפל ב-10 וב-100, עשרות שלמות, דו-ספרתי × חד-ספרתי, חילוק דו-ספרתי |
| 💎 מערת סדר הפעולות | כפל וחילוק לפני חיבור וחיסור, סוגריים |
| 🍕 גן השברים | איזה חלק צבוע, חלק מכמות (¼ של 12), השוואת שברים |
| ⏰ עיר הזמן והמידות | קריאת שעון אנלוגי, כמה דקות עברו, מה תהיה השעה, מטר/ס"מ, ק"ג/גרם, שקל/אגורות, שעה/דקות |
| 📐 ארץ הצורות | צלעות וקודקודים, שמות מצולעים, היקף ריבוע/מלבן/משולש, שטח בספירת ריבועים |
| 📚 ארמון הסיפורים | בעיות מילוליות: כפל וחילוק, שקלים ועודף, מספרים גדולים, שני צעדים, שארית, שבוע ושעות |

### המבחנים 📝

- תחנת מבחן (זהובה) בקצה השביל של כל עולם — נפתחת אחרי שכל 6 השלבים הושלמו.
- 15 שאלות מעורבות מכל שלבי העולם, **תשובה אחת לכל שאלה** (טעות מראה את התשובה הנכונה וממשיכים), עם שעון עצר (בלי הגבלת זמן).
- ציון 0–100. **70 ומעלה עובר ופותח את העולם הבא.** אפשר לחזור על מבחן — נשמר הציון הטוב ביותר.
- מטבעות: מטבע לכל תשובה נכונה, +15 על מעבר, +15 נוספים על 100. מדבקות למבחן ראשון, מעבר, 100, חצי מהמבחנים, כולם, והמבחן הגדול.
- **📋 תעודה** (מהמפה): ציון לכל עולם, ממוצע, ומהמבחנים — **המבחן הגדול** 🏆 (20 שאלות מכל העולמות) שנפתח אחרי שעוברים את כל מבחני העולמות.
- הגדרות המבחן ב-`js/curriculum/noya.js` → `meta.exam`: `questions`, `pass`, `finalQuestions`.

## אלין — גיל הגן

42 שלבים, 7 עולמות: הכל בתמונות (ספירה, השוואות, חיבור חזותי, רצפים, צורות, ספרות, גדלים), כל שאלה מוקראת בקול. בלי מבחנים.

## משותף

- כוכבים על כל שלב, אלבום מדבקות, ודמות מלווה שגדלה עם ההתקדמות.
- **חנות** 🛍️: מטבעות (תשובה נכונה = מטבע, +5 לכל כוכב בסוף סבב) קונים אביזרים, צבעים, רקעים, ביצי הפתעה ודמויות חדשות. הכוכבים לא יורדים אף פעם — רק המטבעות מוצאים. חדר לדמות עם רהיטים וטיפול בדמות.
- מתנה יומית 🎁 במפה.
- עובד **אופליין לגמרי** אחרי ההתקנה. כל ההתקדמות נשמרת על הטאבלט עצמו. בלי חשבונות, בלי שרת, בלי איסוף נתונים.

## הרצה מקומית (לפיתוח)

```
python -m http.server 8765 --directory math-adventure
```

ואז לפתוח `http://localhost:8765` בדפדפן. (אי אפשר לפתוח ישירות כקובץ — נדרש שרת בגלל מודולים ו-service worker.)

### בדיקות הגנרטור

מריצות 1,000 דגימות לכל שלב ומוודאות שכל תשובה נכונה מתמטית ושכל אילוצי השלב מתקיימים (טווחים, המרה/פריטה, לוחות, שארית, סדר פעולות, שברים, שעונים, היקפים, סיפורים), וגם שהמבחנים נבנים נכון.

- בטרמינל: `node tests/run.mjs` (אפשר להוסיף מספר דגימות: `node tests/run.mjs 200`)
- בדפדפן: `http://localhost:8765/tests.html`

## העלאה לאינטרנט (פעם אחת, להתקנה על הטאבלט)

1. ליצור repo ב-GitHub ולדחוף את תיקיית `math-adventure`.
2. Settings → Pages → Deploy from branch → main → root (או `/math-adventure` אם זה תת-תיקייה).
3. לחכות דקה — הכתובת תהיה `https://<שם-משתמש>.github.io/<שם-הריפו>/`.

## התקנה על הטאבלט (סמסונג)

1. **לוודא קול עברי**: הגדרות → ניהול כללי → טקסט לדיבור → שירותי הדיבור של Google → לוודא שיש קול עברית (להוריד בזמן שיש אינטרנט).
2. לפתוח את הכתובת ב-**Chrome** בטאבלט.
3. לשחק סבב אחד כדי לוודא שהקול והאימוג'י נראים טוב.
4. תפריט ⋮ → **"הוספה למסך הבית"** / "התקנת אפליקציה".
5. לבדוק: מצב טיסה → לפתוח מהאייקון → הכל אמור לעבוד.

## עדכון גרסה

אחרי כל שינוי בקבצים: להעלות את מספר הגרסה ב-`sw.js` (שורה ראשונה: `math-adventure-v26` → `v27`), לדחוף ל-GitHub, ולפתוח את האפליקציה פעמיים בטאבלט כשיש אינטרנט (הפתיחה הראשונה מורידה, השנייה מציגה).

**חשוב**: לא למחוק נתוני אתר/דפדפן של הכתובת בטאבלט — שם נשמרת כל ההתקדמות של הבנות. הכוכבים, המטבעות והדמות של נויה מהגרסה הקודמת נשמרים; השלבים החדשים של כיתה ג' מתחילים מההתחלה.

## מבנה הקוד

```
js/curriculum/   הגדרות השלבים (התוכן) — noya.js (כיתה ג' + הגדרות המבחן), alin.js (גיל הגן)
js/engine/       יצירת תרגילים ומבחנים אקראית + כוכבים/ציונים/מדבקות/דמות
js/screens/      המסכים: פרופילים, מפה (עם תחנת מבחן), תרגיל/מבחן, תעודה, פרסים, דמות, חנות, חדר, הורים
js/ui/           רכיבים: לוח מספרים, כרטיסים, ציורי SVG (שעון, שברים, צורות), דמות, קונפטי
tests/           בדיקות הגנרטור (Node + דפדפן)
sw.js            service worker — עבודה אופליין (להעלות גרסה בכל עדכון!)
```
