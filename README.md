# הרפתקת המתמטיקה 🔢

אפליקציית תרגול חשבון לנויה (כיתה ג') ולאלין (גיל הגן) — לשימוש משפחתי, על טאבלט. **נטו לימוד**: בלי חנות, בלי דמויות ובלי פרסים. המטרה: להפוך את הבנות לאלופות במתמטיקה, ולתת להורים דוח מפורט על החוזקות והחולשות.

## איך זה עובד

- **רשימת שלבים בקוביות**, לפי עולמות. כל שלב = סבב של 10 שאלות, כוכבים לפי טעויות בניסיון ראשון (0 טעויות = 3 כוכבים). שלב נפתח אחרי שהקודם הושלם.
- **תרגול מומלץ 🎯** בראש הרשימה: המערכת בוחרת את השלב הפתוח החלש ביותר (לפי הדיוק בפועל), ואם אין חולשה — את השלב הבא שעוד לא הושלם ב-3 כוכבים, או חזרה על מה שתורגל מזמן.
- **מבחן בסוף כל עולם** (נויה): נפתח אחרי סיום כל 6 השלבים. 15 שאלות מעורבות, תשובה אחת לכל שאלה (טעות מראה את התשובה הנכונה), שעון עצר בלי הגבלה, ציון 0–100. **70 ומעלה עובר ופותח את העולם הבא.** נשמר הציון הטוב ביותר.
- **תעודה 📋** לילדה: ציון לכל עולם, ומהתעודה נפתח **המבחן הגדול** 🏆 (20 שאלות מכל העולמות) אחרי מעבר כל מבחני העולמות.
- **דוח הורים 📊** (מסך הפתיחה ← הורים): לכל ילדה — שאלות שנענו, דיוק כולל, זמן תרגול, ימים פעילים; **חוזקות וחולשות** לפי שלב; לכל שלב אחוז דיוק, מספר שאלות (תרגול ומבחן), זמן ממוצע לשאלה וסטטוס (💪 חוזק / 👍 בסדר / ⚠️ לתרגול / 🌱 בתהליך); ציוני מבחנים; סבבים אחרונים. הדיוק נמדד לפי הניסיון הראשון בכל שאלה.
- עובד **אופליין לגמרי** אחרי ההתקנה. כל הנתונים נשמרים על הטאבלט עצמו. בלי חשבונות, בלי שרת.

## נויה — כיתה ג'

60 שלבים ב-10 עולמות + מבחן לכל עולם:

| עולם | נושא |
|---|---|
| 🔢 עיר המספרים הגדולים | המבנה העשרוני עד 1000: מאות/עשרות/אחדות, פירוק, השוואה (‹ › =), זוגי/אי-זוגי, ±10/±100, עיגול |
| 🌉 גשר החיבור והחיסור | חיבור וחיסור עד 1000 עם ובלי המרה/פריטה, מספר חסר |
| 🏝️ אי לוח הכפל | שליטה בכל לוח הכפל, גורם חסר, סדרות ודילוגים |
| ❄️ ממלכת החילוק | חילוק בכל המחלקים, **חילוק עם שארית** (שני חלונות תשובה) |
| 🌋 הר הכפל הגדול | כפל ב-10 וב-100, עשרות שלמות, דו-ספרתי × חד-ספרתי, חילוק דו-ספרתי |
| 💎 מערת סדר הפעולות | כפל וחילוק לפני חיבור וחיסור, סוגריים |
| 🍕 גן השברים | איזה חלק צבוע, חלק מכמות (¼ של 12), השוואת שברים |
| ⏰ עיר הזמן והמידות | שעון אנלוגי, כמה דקות עברו, מה תהיה השעה, מטר/ס"מ, ק"ג/גרם, שקל/אגורות, שעה/דקות |
| 📐 ארץ הצורות | צלעות וקודקודים, שמות מצולעים, היקף, שטח בספירת ריבועים |
| 📚 ארמון הסיפורים | בעיות מילוליות: כפל וחילוק, שקלים ועודף, מספרים גדולים, שני צעדים, שארית, שבוע ושעות |

הגדרות המבחן ב-`js/curriculum/noya.js` → `meta.exam`: `questions`, `pass`, `finalQuestions`.

## אלין — גיל הגן

42 שלבים, 7 עולמות: הכל בתמונות (ספירה, השוואות, חיבור חזותי, רצפים, צורות, ספרות, גדלים), כל שאלה מוקראת בקול. בלי מבחנים. הדוח להורים עוקב גם אחריה.

## הרצה מקומית (לפיתוח)

```
python -m http.server 8765 --directory math-adventure
```

ואז לפתוח `http://localhost:8765` בדפדפן. (אי אפשר לפתוח ישירות כקובץ — נדרש שרת בגלל מודולים ו-service worker.)

### בדיקות הגנרטור

1,000 דגימות לכל שלב: כל תשובה נכונה מתמטית וכל אילוצי השלב מתקיימים, וגם המבחנים נבנים נכון.

- בטרמינל: `node tests/run.mjs` (אפשר להוסיף מספר דגימות: `node tests/run.mjs 200`)
- בדפדפן: `http://localhost:8765/tests.html`

## העלאה לאינטרנט (פעם אחת, להתקנה על הטאבלט)

1. ליצור repo ב-GitHub ולדחוף את תיקיית `math-adventure`.
2. Settings → Pages → Deploy from branch → main → root.
3. לחכות דקה — הכתובת תהיה `https://<שם-משתמש>.github.io/<שם-הריפו>/`.

## התקנה על הטאבלט (סמסונג)

1. **לוודא קול עברי**: הגדרות → ניהול כללי → טקסט לדיבור → שירותי הדיבור של Google → לוודא שיש קול עברית.
2. לפתוח את הכתובת ב-**Chrome** בטאבלט.
3. תפריט ⋮ → **"הוספה למסך הבית"** / "התקנת אפליקציה".
4. לבדוק: מצב טיסה → לפתוח מהאייקון → הכל אמור לעבוד.

## עדכון גרסה

אחרי כל שינוי בקבצים: להעלות את מספר הגרסה ב-`sw.js` (שורה ראשונה: `math-adventure-v27` → `v28`), לדחוף ל-GitHub, ולפתוח את האפליקציה פעמיים בטאבלט כשיש אינטרנט (הפתיחה הראשונה מורידה, השנייה מציגה). אם עדיין רואים גרסה ישנה: לסגור את האפליקציה לגמרי ולפתוח שוב, או הגדרות ← אפליקציות ← המשחק ← אחסון ← **נקה מטמון** (לא "נקה נתונים"!).

**חשוב**: לא למחוק נתוני אתר/דפדפן של הכתובת בטאבלט — שם נשמרים כל הנתונים. שדות מהגרסאות הקודמות (מטבעות, דמות, מדבקות) מנוקים אוטומטית; הכוכבים והציונים נשמרים.

## מבנה הקוד

```
js/curriculum/   הגדרות השלבים (התוכן) — noya.js (כיתה ג' + הגדרות המבחן), alin.js (גיל הגן)
js/engine/       generator.js — יצירת תרגילים ומבחנים; rewards.js — כוכבים, נעילות, מבחנים, מדדי שליטה והמלצה
js/screens/      profileSelect, levels (רשימת הקוביות), exercise (תרגול/מבחן), report (תעודה), parent, parentReport (דוח)
js/storage.js    אחסון: כוכבים, ציוני מבחנים, מעקב מיומנויות (כל תשובה), סבבים אחרונים
js/ui/           לוח מספרים, כרטיסים, ציורי SVG (שעון, שברים, צורות), קונפטי
tests/           בדיקות הגנרטור (Node + דפדפן)
sw.js            service worker — עבודה אופליין (להעלות גרסה בכל עדכון!)
```
